# KyumeiKosyu Frontend

React ベースの予約システムを構築するためのフロントエンド土台です。

## Stack

- Vite
- React
- TypeScript
- React Router
- ESLint
- Prettier
- Vitest

## Commands

```bash
npm install
npm run dev
npm run dev:server
npm run dev:client
npm run build
npm run check:server
npm run lint
npx vitest run
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
```
