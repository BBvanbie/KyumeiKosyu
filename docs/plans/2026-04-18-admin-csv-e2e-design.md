# 管理者 CSV 出力 E2E 設計

## 目的

管理者ログインから予約一覧の CSV 出力までを、実ブラウザで回帰確認できるようにする。CSV は project 直下へ保存し、保存後に中身まで検証する。

## 方針

- Playwright を導入し、`npm run dev` でクライアントと API を同時起動した状態で E2E を走らせる。
- 予約データは UI で作るのではなく、テスト内の API セットアップで作成する。これによりカレンダーや多段フォームの揺れに依存せず、CSV 出力導線そのものに集中できる。
- 管理者ログインは実 UI から行い、その後 `予約一覧` で `CSV対象年月` を指定して `CSV出力` を押す。
- ダウンロードは Playwright の `download.saveAs(...)` を使って `C:\practice\KyumeiKosyu\` 直下に保存する。
- 保存された CSV を読み込み、作成した予約の予約番号・氏名・電話番号・受講種別が含まれていることを確認する。

## 対象

- Playwright 設定
- E2E テスト 1 本
- 実行用 package script

## 非対象

- CSV 出力 UI の仕様変更
- バックエンド API のテスト専用エンドポイント追加
- 既存の unit test 置き換え

## リスクと対策

- 予約日が既存データと衝突する可能性がある
  - 未来日を十分先にずらし、作成前に availability を見て空きを使う
- ダウンロードファイルが project 直下に残る
  - テスト前に同名ファイルを消し、テスト後も削除する
- 管理者認証やシード前提が環境差分で壊れる
  - 既定値 `admin / Change123` を使い、README と seed に沿った前提に揃える
