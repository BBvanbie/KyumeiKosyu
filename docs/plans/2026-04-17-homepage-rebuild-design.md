# ホーム画面再設計

## 目的

ホーム画面を Airbnb 風の疑似検索 UI から切り離し、救命講習予約システム専用の案内ページとして再構築する。主目的は予約導線であり、案内文は管理者が設定画面から更新できるようにする。

## 方針

- ホームのファーストビューは予約導線を最優先にする
- 検索バー、カテゴリ、旅行サイト風カードは廃止する
- 予約 CTA と管理者ログインを明確に分ける
- 案内文や注意事項は別セクションで整理する

## 管理対象の文言

- メイン見出し
- サブ説明文
- 案内セクション見出し
- 案内本文

## ホームの構成

1. ヒーロー
   - サービス名
   - 管理可能な見出し
   - 管理可能な説明文
   - `予約をはじめる`
   - `管理者ログイン`
2. 利用案内
   - 管理可能な見出し
   - 管理可能な本文
   - 予約までの流れを 3 ステップで表示
3. 注意事項
   - 電話確定
   - 英語版講習の注意
   - 予約不可日と受付停止
