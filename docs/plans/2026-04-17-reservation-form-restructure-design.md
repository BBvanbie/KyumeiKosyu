# 予約フォーム再構成設計

## 目的

救命講習予約フォームを、団体予約向けの業務要件に合わせて再構成する。英語版講習の条件分岐、追加テキスト購入、必須項目の整理を加え、確認画面と送信 API まで一貫した構成にする。

## フォーム構成

1. 予約者情報
2. 受講団体情報
3. 備考
4. 追加テキスト購入
5. 受講内容

## 入力ルール

- 受講団体情報は `団体名 / 実施場所住所 / 受講対象者` に整理する
- 上記 3 項目はすべて必須
- 電話番号は数値のみ入力し、画面上は自動でハイフンを補完する
- 受講内容は既存どおり 3 行まで入力できる

## 英語版講習の分岐

- 受講内容に `普通（英語版）` が 1 行でも含まれる場合、予約全体に対して `通訳手配の可否` を表示する
- `通訳手配が可能` の場合だけ確認画面へ進める
- `通訳手配が不可` の場合は、消防署で電話受付になる旨のモーダルを表示し、Web 予約は止める
- 英語版講習が含まれる場合、`日本語テキスト必要部数` と `英語版テキスト必要部数` を必須入力にする

## 追加テキスト購入

- 備考と受講内容の間に追加テキスト購入セクションを置く
- `追加購入されたい方はこちらをチェック` のチェックボックスで入力エリアを有効化する
- 対象テキストは次の 5 種類
  - 普通（新規）
  - 普通（再講習）
  - 普通（英語版）
  - 上級（新規）
  - 上級（再講習）

## データ構造

- 予約単位で `interpreterAvailable` を保持する
- 予約単位で `japaneseTextbookCount` と `englishTextbookCount` を保持する
- 予約単位で `wantsAdditionalTextbooks` と追加購入部数の内訳を保持する
- 団体の実施場所は `venueAddress` として保持する

## 確認画面

- 団体情報、英語版分岐、必要テキスト部数、追加購入部数を表示する
- 英語版が含まれる場合の注意文は確認画面でも維持する
