# Docs Structure

このプロジェクトの Markdown ドキュメントは `docs` 配下に整理して保存する。

## Directories

- `docs/designs`
  要件定義、画面設計、アーキテクチャ方針、デザイン方針
- `docs/plans`
  実装計画、作業分解、フェーズ計画

## Rules

- 実装前の設計は `docs/designs/YYYY-MM-DD-<topic>.md`
- 実装計画は `docs/plans/YYYY-MM-DD-<topic>.md`
- 一時メモは置かず、残す価値のある内容だけを保存する
- 同じテーマで設計と計画を分ける場合、ファイル名の主題を揃える
